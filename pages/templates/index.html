API

Todas las rutas son ficheros JSON estáticos servidos por GitHub Pages, con CORS abierto. Una ruta sin datos devuelve 404.

RutaContenido
/v1/latest.jsonÚltima publicación, todas las divisas
/v1/rates/{YYYY-MM-DD}.jsonCualquier día desde {{FIRST_DATE}}. En fines de semana y festivos devuelve la publicación anterior.
/v1/history/{divisa}.jsonSerie histórica completa de una divisa
/v1/history/{divisa}/{año}.jsonSerie de una divisa en un año
/v1/currencies.jsonTodas las divisas publicadas alguna vez, con su periodo y si siguen activas
/v1/meta.jsonFuente, cobertura y fecha de generación
 
curl {{SITE_URL}}/v1/rates/2025-03-23.json
{
  "base": "EUR",
  "date": "2025-03-21",
  "requested_date": "2025-03-23",
  "source": "ECB",
  "rates": { "AUD": "1.724", "BRL": "6.1911", "…": "…", "USD": "1.0827" }
}
  • Los tipos expresan cuántas unidades de la divisa equivalen a 1 EUR.
  • Los valores son cadenas decimales tal como las publica el BCE, para no perder precisión.
  • date es la publicación usada; requested_date, la fecha pedida. Si son distintas, era fin de semana o festivo.
  • El BCE publica hacia las 16:00 (hora de Fráncfort) cada día hábil TARGET.

Librería PHP

Los mismos datos, con caché y consultas por rango, desde Packagist:

composer require codecruz/currency-flow
$flow = CodeCruz\CurrencyFlow\CurrencyFlow::ecb();
$flow->rate('USD', '2025-03-23')->value; // "1.0827"

Fuente: Banco Central Europeo. Los tipos de referencia se publican solo a título informativo.
